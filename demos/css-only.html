A popover that leaves as nicely as it arrives.

transition-behavior: allow-discrete keeps it in the top layer until the fade-out finishes. Open it, then press Escape or click outside.

The whole recipe

Exit state on the element, open state on :popover-open, start state in @starting-style.

[popover] {
  opacity: 0;
  transition: opacity .16s,
    overlay .16s allow-discrete,
    display .16s allow-discrete;
}
[popover]:popover-open { opacity: 1; }
@starting-style {
  [popover]:popover-open { opacity: 0; }
}
